# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.4.1   | ✅ |
| 0.4.0   | ❌ |
| < 0.4.0 | ❌ |

## Reporting a Vulnerability

Do NOT open a public Issue for security bugs.

Use GitHub **Security > Report a vulnerability** on this repo.

Include:
- App version, e.g. 0.4.1
- What you found
- Steps to reproduce

I will confirm within 3 days, and tell you if it is accepted and when a fix is planned. Please do not publish it until a fix is released.
